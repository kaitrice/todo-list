
# ToDo List

UI json todo list 


## Features

- Add task(s)
- Remove task(s) or all
- Complete task(s)
- List all tasks
- Print commands
- Save to json file after quitting


## Run Locally

Clone the project

```bash
  git clone https://github.com/kaitrice/todo-list.git
```

Go to the project directory

```bash
  cd todo-list
```

Start the server

```bash
  py main.py
```
